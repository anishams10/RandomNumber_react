# Random Number Generator

A simple Random Number Generator built using React.js.

## Features
- Generates a random number between 1 and 100.
- Displays the generated number dynamically.
- Uses React `useState` to manage state.
- Uses button click events to generate numbers.
- Displays a placeholder message before generating a number.

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS

## How to Run

1. Clone the repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL in your browser.

## Project Purpose

This project was created to practise React state management, event handling, and conditional rendering.
